# 0. LEIA PRIMEIRO

Este arquivo é a especificação principal do produto.

Antes de escrever qualquer código:

1. Leia este AGENTS.md inteiro.
2. Analise o repositório existente.
3. Identifique stack, arquitetura e componentes reutilizáveis.
4. Valide os requisitos.
5. Crie plano técnico.
6. Crie arquitetura de informação.
7. Crie design system.
8. Use Impeccable para UX/UI.

# 10. O QUE "PREMIUM" SIGNIFICA

Premium NÃO significa adicionar decoração.

Premium significa:

- excelente tipografia
- excelente fotografia
- muito espaço
- hierarquia clara
- conteúdo organizado
- animações discretas
- microinterações
- mapas excelentes
- gráficos legíveis
- ótima experiência mobile
- detalhes refinados

Evitar:

- excesso de cards
- excesso de gradientes
- texto gigante desnecessário
- dezenas de CTAs
- visual de template político
- visual genérico de IA
- interface carregada

# 22. VALIDAÇÃO DOS MUNICÍPIOS

Antes de inserir em produção:

Para cada entrada:

1. Normalizar nome.
2. Consultar cadastro oficial do IBGE.
3. Encontrar código IBGE.
4. Confirmar que pertence à Bahia.
5. Obter coordenadas.
6. Obter geometria territorial.
7. Registrar divergências.
8. Fazer revisão humana.

Não tentar "adivinhar" município inválido.

Se não encontrar:

status = NEEDS_REVIEW

# 110. DIRETRIZ FINAL

Bahia do Sul deve parecer uma plataforma construída para durar décadas,
não uma página feita para uma eleição.

O visitante deve conseguir:

CONHECER
↓
ENTENDER
↓
EXPLORAR
↓
CONFERIR
↓
PARTICIPAR

Bahia do Sul é o protagonista.

História, dados e fontes formam a base.

Os participantes contemporâneos aparecem dentro dessa história,
com suas posições corretamente atribuídas.

O objetivo de UX é tornar uma proposta territorial complexa
compreensível, transparente e verificável para qualquer pessoa.

Nunca sacrificar credibilidade por impacto visual.

Nunca sacrificar clareza por quantidade de informação.

Nunca sacrificar precisão por narrativa.

Use IMPECCABLE até que a experiência esteja visualmente e
funcionalmente excepcional.
